# GAME Addons: extra methods ported to Genomic API Model Evaluation

 This repository contains the code and accompanying data for the MPRALegNet Predictor and CAGI5 (Kircher et al.) Evaluator wrapped up to use the GAME API by Ishika Luthra, Carl G. de Boer et al., see https://github.com/de-Boer-Lab/Genomic-API-for-Model-Evaluation/tree/main

## 1. CAGI5 (Kircher 2019) Evaluator

 - The implementation and the usage instructions for Evaluator, which was built on top of the CAGI5 saturation mutagenesis MPRA data: [HERE](https://github.com/autosome-ru/GAME-LegNet-predictor-CAGI5-evaluator/tree/master/Kircher_2019_Evaluator).

 - The implementation **(extracted genome sequences included to evaluator data)** and the usage instructions for Evaluator, which was built on top of the CAGI5 saturation mutagenesis MPRA data **(v2)**: [HERE](https://github.com/autosome-ru/GAME-LegNet-predictor-CAGI5-evaluator/tree/master/Kircher_2019_Evaluator_v2).

 - Pre-built containers hosted on [Hugging Face](https://huggingface.co/datasets/Ni-os/Kircher-container) DOI: 10.57967/hf/906
